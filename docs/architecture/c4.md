## Fluxo de uma execução de IA

```mermaid
sequenceDiagram
  participant U as Usuário
  participant W as Web
  participant A as API
  participant Q as Fila
  participant O as Orquestrador
  participant P as Provedor de IA
  U->>W: Dispara execução na tarefa
  W->>A: POST /tasks/:id/agent-runs
  A->>Q: enfileira
  Q->>O: run(agentRunId)
  loop pipeline (planejar … documentar)
    O->>P: generate(contexto, instruções, onToken)
    P-->>O: resumo + tool calls (stream de tokens vira SSE)
    O->>O: authorizeToolCall (tenant, RBAC, política)
  end
  O-->>A: approval_required / completed
  A-->>W: SSE (status + tokens)
  U->>W: Aprova ferramentas de escrita
```
